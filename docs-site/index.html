The PowerToys & DevOps Companion for Ubuntu

Knobu unifies Microsoft PowerToys productivity utilities, macOS-style Top Bar status and Automations, Cloud & Kubernetes DevOps workflows, System maintenance tools, and full GNOME Desktop customization in one native daemon + settings app.

Quick Install

sudo dpkg -i knobu_0.5.1_all.deb
sudo apt-get install -f -y
sudo usermod -aG input $USER   # re-login once for kernel evdev hotkeys & touchpad gestures
knobu enable                   # start background daemon and autostart on login

Architecture Overview

DevOps on Cloud

Active AWS CLI profile & STS verification, Kubernetes context switcher, Docker container controls, Port Manager, /etc/hosts editor, DNS/SSL/CIDR/TCP diagnostics, and Cron scheduler.

System Tools

System Cleaner (caches, crash dumps, apt), multi-source Package Uninstaller (apt/snap/flatpak/npm/pip/brew), Environment Variables manager, and File Locksmith.

Power Tools

Command Bar (Alt+Space), Clipboard History (Super+V), Window Manager (Super+Alt+T), Screen Ruler (Super+Shift+M), ZoomIt, Quick Accent, and Workspaces.

Appearance & System

Startup Apps manager, system/monospace fonts & hinting, cursor/icon/GTK themes, light/dark wallpapers, Mutter display resolution & fractional scaling, sound profiles, and per-app notifications.

Rule Automations

Daemon-native When -> If -> Then engine supporting Wi-Fi, VPN, battery, AC power, running apps, folder watchers, schedules, screen lock, plus 1-click DevOps templates.

GitHub Gist Cloud Sync

Offline JSON export/restore plus encrypted-at-rest GitHub PAT authentication to sync settings automatically or on a schedule to a secret GitHub Gist.
