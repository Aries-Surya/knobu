Troubleshooting & Wayland Architecture

Always on Top & FancyZones on Native GNOME Wayland

Native Wayland apps do not expose EWMH X11 window IDs to wmctrl. Knobu bundles the native GNOME Shell extension knobu-window-bridge@knobu.org which exposes a session D-Bus bridge to Mutter (make_above(), unmake_above(), move_resize_frame()). If newly installed, log out and back into GNOME once so GNOME Shell loads the user extension.

How to Turn Off Always on Top

Focus the pinned window and press Super+Alt+T again, click Always on Top in the Top Bar Tray -> Quick Tools, run knobu always-on-top, or right-click the app's title bar and uncheck Always on Top.

Display Scaling & Safe Revert

When changing monitor resolution or scaling inside Appearance & System -> Display Resolution & Scaling, Knobu automatically displays a 15-second confirmation prompt. If you do not confirm (for example, if a resolution renders blank), Knobu restores your previous working configuration automatically.

Quick Bypass & Daemon Reload

knobu bypass on        # immediately pause all hardware grabs for OS troubleshooting
knobu bypass off       # re-enable Knobu utilities
systemctl --user reload knobu
