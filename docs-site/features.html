DevOps CLI Commands

knobu aws-profile                # List profiles (active starred)
knobu aws-profile prod           # Switch AWS_PROFILE + region in live systemd env
knobu aws-whoami                 # Verify active AWS STS Account & ARN
knobu kube-context               # List Kubernetes contexts
knobu kube-context prod-eks      # Switch kubectl active context
knobu ports                      # List listening TCP/UDP ports & PIDs
knobu dns example.com MX         # Query DNS records
knobu ssl-check github.com       # Inspect TLS expiry & SANs
knobu cidr 10.20.0.0/22          # Subnet calculation

Universal Bypass Mode

Every module and tool section includes a dedicated Bypass toggle at the top of its settings page (plus Master Bypass via tray or knobu bypass toggle) so you can immediately pass through to native OS behavior whenever troubleshooting desktop conflicts or gaming.
