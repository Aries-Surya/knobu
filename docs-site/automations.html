Automation Engine & GitHub Gist Sync

Automation Engine Triggers, Conditions & Actions

Triggers (When)

wifi_ssid, wifi_disconnect, vpn_connected, vpn_disconnect, battery_below, battery_above, ac_power, app_running, app_closed, screen_lock, folder_new_file, time_of_day, interval.

Conditions (If)

always, wifi_is, wifi_in (comma-separated SSIDs), vpn_active, vpn_inactive, battery_below, battery_range (e.g. 20-80), on_ac, on_battery, app_is_running, time_window (HH:MM-HH:MM).

Actions (Then)

notify, set_theme, switch_aws, switch_kube, set_bypass, set_awake, set_dnd, mute_mic, launch_workspace, run_command.

GitHub Gist Cloud Backup Setup

  1. Create a GitHub Personal Access Token (Fine-grained or Classic) with only the gist scope.
  2. Open General -> Cloud Backup (GitHub Gist), paste your token, and click Verify. (Tokens are stored locally in ~/.config/knobu/cloud_sync.json with mode 0600 and are never uploaded into the Gist.)
  3. Click Push to Gist to create a secret Gist containing config.toml, automations.json, and workspaces.json.
  4. Optionally enable Auto-Sync on Configuration Changes or select a periodic background interval (15m / 1h / Daily).
